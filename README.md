📚 Second-Hand Book Marketplace Prototype
📖 Project Overview

This project is a basic prototype of an e-commerce website developed for buying and selling second-hand books. The platform is designed to provide an affordable and convenient way for users to exchange books from different genres such as academic, fiction, non-fiction, and competitive exam books.

The website allows sellers to upload book details including title, genre, condition, and price, while buyers can browse and search for books according to their preferences. Buyers and sellers can communicate directly to decide suitable delivery locations and payment methods.

The prototype is developed using basic web technologies including HTML, CSS, and JavaScript. The main aim of the project is to promote the reuse of books, reduce the cost of educational resources, and encourage sustainable usage of books.
